# AdForge AI

RAG-powered SaaS for generating brand-grounded advertising creative.

## Features
- Per-user Brand Brain powered by RAG
- Campaign briefs for Meta, Google Ads, LinkedIn, and TikTok
- AI-generated benefit, problem-solution, proof, and curiosity angles
- Claim-safety instructions to reduce unsupported AI claims
- Creative feedback and learning loop
- Passwordless email authentication
- PostgreSQL persistence through Hatchable

## Architecture
Hatchable + PostgreSQL + Hatchable Knowledge/RAG + Hatchable AI + Alpine.js.

## Live app
https://adforge-ai-i7ik.hatchable.site

## Deploy
This repository contains the source deployed to Hatchable. Deploy it through Hatchable using the project files and platform configuration.

> The current Hatchable project is configured as a personal/private project. Change its Visibility setting to Public in Hatchable if you want unrestricted public visitors.
